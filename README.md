# reducao-de-dimensionalidade
📉 Projeto de Redução de Dimensionalidade
✨ Versão Visual em HTML, CSS e JavaScript

Este repositório apresenta um projeto de Redução de Dimensionalidade, inicialmente desenvolvido em Python para fins acadêmicos e experimentais.
Posteriormente, todo o conceito foi transformado em uma aplicação visual utilizando HTML, CSS e JavaScript, permitindo demonstrar o funcionamento do algoritmo de forma mais intuitiva e educativa.

🎯 Objetivo do Projeto

Implementar algoritmos de redução de dimensionalidade para visualizar dados multidimensionais.

Demonstrar, de maneira prática e interativa, como técnicas como PCA e outras reduzem atributos mantendo o máximo de informação possível.

Tornar o processo visual, didático e simples através de uma interface web.

🧠 Tecnologias Utilizadas
✅ Backend Analítico (versão original)

Python

NumPy

Pandas

Scikit-learn (PCA, Normalização etc.)

Matplotlib / Seaborn (visualizações)

✅ Interface Web (versão visual)

HTML5 — Estrutura da aplicação

CSS3 — Estilização responsiva e moderna

JavaScript — Lógica visual/interativa para simular os passos do PCA

Gráficos utilizando Canvas ou SVG (conforme sua implementação)

🧩 O que a versão web faz?

Exibe de forma clara a ideia de projeção de dados em menos dimensões

Mostra comparações entre espaço original e reduzido

Apresenta animações/representações visuais dos vetores principais (ou equivalente)

Facilita o entendimento de como a redução funciona na prática, sem depender de código Python
